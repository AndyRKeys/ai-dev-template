# Security Policy

## Reporting a Vulnerability

Please do **not** open a public GitHub issue for security vulnerabilities.

Report suspected vulnerabilities privately to the repository owner through the preferred private contact method for this project.

Include:
- A description of the issue
- Steps to reproduce
- Potential impact
- Any suggested mitigation

## Handling Guidance

- Treat exposed secrets as compromised and rotate them immediately
- Prefer private disclosure and coordinated fixes over public discussion
