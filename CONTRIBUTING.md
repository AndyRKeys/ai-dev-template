# Contributing

Thanks for contributing.

## Workflow

- Create or reference an issue before starting work
- Branch from `dev`, not `main`
- Keep PRs small and focused
- Fill in the PR template completely
- Update docs in the same PR when behaviour or workflow changes

## AI-assisted contributions

- Read `AGENTS.md` before making changes
- Follow the scope, security, and execution-safety rules there
- Use example or sanitised config files instead of reading secret-bearing files directly
- Never execute destructive operations without a dry-run and explicit approval

## Review expectations

- Include a clear test plan with exact commands where applicable
- Note risks, limitations, and follow-up items in the PR
